# 将一张图片转化为 PCB，可导入 EDA

## 效果流程

```
colorPresets.json   # 阻焊颜色预设（由 00编辑预设.py 管理）
   ↓ 00编辑预设.py  (可选 — 自定义阻焊颜色)
origin.png          # 原始 PCB 艺术画（也支持拖放任意图片到脚本上）
   ↓ 01颜色简化.py
01/01.png           # 6 色量化图
   ↓ 工具：众数滤波.py (可选 — 众数滤波去除细线杂质)
01/01.png           # 滤波后的量化图
   ↓ 02颜色分离.py
02/*.png            # 6 张颜色遮罩
   ↓ 03颜色合并.py
03/*.png            # 5 张 PCB 图层
   ↓ 04图片边框.py
04/*.png            # 带对齐边框的图层（白底）
   ↓ 05反相.py
05/*.png            # 反相图层（黑底）→ 适配不同 EDA 的背景约定
```

## 环境依赖

- Python 3

- NumPy

```bash
pip install opencv-python numpy
```

## 快速开始

按顺序运行以下脚本：

```bash
# 第 0 步（可选）：管理阻焊颜色预设
python 00编辑预设.py
# 交互式创建/编辑/删除预设，保存到 colorPresets.json

# 第 1 步：选择阻焊预设，将原图量化为 6 种颜色
python 01颜色简化.py
# 或拖放图片到脚本上：python 01颜色简化.py myimage.png
# 终端选择预设或手动输入 → 弹窗预览 → 按任意键关闭
# 输出: 01/01.png + 01/palette.json

# 可选：众数滤波，去除量化图中残留的细线杂质
python 工具：众数滤波.py
# 交互式选择窗口大小（建议 5），用邻近颜色替换 1-3px 宽的杂色细线
# 预览后覆盖保存 01/01.png

# 第 2 步：分离每种颜色为独立遮罩
python 02颜色分离.py
# 自动读取 01/palette.json → 输出 6 张遮罩到 02/

# 第 3 步：将遮罩合成为 PCB 图层
python 03颜色合并.py
# 输出 5 张图层到 03/

# 第 4 步：添加棋盘格对齐边框
python 04图片边框.py
# 输出最终文件到 04/

# 第 5 步（可选）：反相图层，适配不同 EDA
python 05反相.py
# 将 04/ 的所有图片反相输出到 05/
```

最终使用 `04/` 或 `05/` 目录下的文件导入 EDA：
- `04/` — 白底图层（默认，适用于大多数 EDA）
- `05/` — 黑底图层（适用于将黑色作为背景的 EDA）

## 颜色体系

原始艺术画使用 6 种颜色来编码 PCB 的层信息。每种颜色代表不同的铜皮/阻焊组合：

| 颜色 | 色值 | 含义 |
|------|------|------|
| 深阻焊 `DSolder` | 有阻焊无铜皮的颜色，自行填写 | 正面：有阻焊，无铜皮 |
| 浅阻焊 `LSolder` | 有阻焊有铜皮的颜色，自行填写 | 正面：有阻焊，有铜皮 |
| 黑 `Black` | `#061008` | 正面：无阻焊，有铜皮（焊盘） |
| 白 `White` | `#E6EAEB` | 正面丝印层 |
| 深绿 `DGreen` | `#193522` | 正面无阻焊，背面有阻焊 |
| 浅黄 `LYellow` | `#F9E195` | 正面无阻焊，背面无阻焊 |

## 输出图层

| 文件名 | 图层 | 类型 | 合成公式 |
|--------|------|------|----------|
| `topCu.png` | 顶层铜皮 | 正片 | 浅阻焊 + 黑 |
| `topSolder.png` | 顶层阻焊 | **负片** | `NOT(深阻焊+浅阻焊+白+黑)` |
| `topText.png` | 顶层丝印 | 正片 | 白 |
| `bottomCu.png` | 底层铜皮 | 正片 | 深绿 + 浅黄 |
| `bottomSolder.png` | 底层阻焊 | **负片** | `NOT(深绿)` |

> **负片说明**：阻焊层为负片——**白色 = 开窗（露铜）**，黑色 = 覆盖阻焊。这与 PCB 厂家的惯例一致。

## 导入立创 EDA

在立创 EDA 中新建 PCB，依次导入 `04/` 下的图片：

| 文件 | 立创 EDA 对应层 |
|------|----------------|
| `topCu.png` | 顶层铜皮 |
| `topSolder.png` | 顶层阻焊 |
| `topText.png` | 顶层丝印 |
| `bottomCu.png` | 底层铜皮 |
| `bottomSolder.png` | 底层阻焊 |

导入时注意设置正确的 DPI / 缩放比例以匹配实际尺寸。

## 自定义颜色

### 使用预设编辑器（推荐）

运行 `00编辑预设.py`，可交互式管理阻焊预设：

```bash
python 00编辑预设.py
# 主菜单：
#   0  — 创建新预设（输入名称 + DSolder + LSolder）
#   1-7 — 编辑已有预设
#         0 — 删除该预设
#         1 — 修改 DSolder
#         2 — 修改 LSolder
#         3 — 修改名称
#   任意输入框输入 exit/quit 回到上一级
```

预设保存在 `colorPresets.json`，`01颜色简化.py` 启动时自动从该文件读取。

### 在 01 脚本中手动输入

运行 `01颜色简化.py` 时选 `0` 可手动输入阻焊颜色（当场生效，不保存到预设文件）。

### 修改固定颜色

编辑 `01颜色简化.py` 中的 `FIXED` 字典可修改四个固定颜色（`DGreen`/`LYellow`/`Black`/`White`），一般无需改动。

## 进阶处理

1. 运行脚本前，可先在 Photoshop 或画图工具中手工修整 `origin.png`，清理杂色、调整边缘
2. 颜色量化后如不满意，可调整 `hexColors` 的色值使其更接近原图实际用色
3. 量化后如有杂色细线，可用 `工具：众数滤波.py` 做众数滤波去除
4. 生成的图层可直接在 EDA 中进一步手动编辑

```
├── colorPresets.json       # 阻焊颜色预设（7 个内置 + 可自定义）
├── 00编辑预设.py            # 步骤0：管理阻焊预设
├── 01颜色简化.py            # 步骤1：颜色量化
├── 工具：众数滤波.py         # 可选：众数滤波去除细线杂质
├── 02颜色分离.py            # 步骤2：颜色分离为遮罩
├── 03颜色合并.py            # 步骤3：遮罩合成为 PCB 图层
├── 04图片边框.py            # 步骤4：添加对齐边框
├── 05反相.py                # 步骤5：反相图层（适配不同 EDA 背景约定）
├── 附录：颜色合成公式.txt    # 参考：颜色与图层的对应关系
├── 01/                     # 步骤1 输出
├── 02/                     # 步骤2 输出（颜色遮罩）
├── 03/                     # 步骤3 输出（PCB 图层）
├── 04/                     # 步骤4 输出（带边框，白底）
└── 05/                     # 步骤5 输出（反相，黑底）
```
